Review Plan 계약: Run마다 .harness/review-plans/<run_id>.json 파일 하나를 둔다. 새 계획(v2)은 schema_version, run_id, work_item_id, snapshot_max_seq(계획에 포함할 마지막 EVT 순번), decisions(Artifact·Evidence 등록 판단과 이유), excluded_event_ids(등록하지 않을 EVT ID)를 담는다. 두 목록이 해당 순번까지의 모든 EVT를 빠짐없이 한 번씩 포함하는지 검증한다. 기존 v1의 events 계획도 읽고 복구한다. 판단 파일은 재작성하지 않으며, 실제 적용 결과의 정본은 DB다.

progressed: 이번 Run이 성공하면 Run은 succeeded, WI는 ready가 된다. 남은 작업의 next_action(다음 행동)을 적거나, AC가 모두 충족됐으면 completion_recommended(사용자 완료 권장)를 지정한다. WI의 done은 별도 요청이다.
